# 🤖 카봇 한글 쓰기 · 카봇 시계 · 카봇 영어 출동 미션

아이를 위한 **헬로카봇 한글 쓰기 + 카봇칩 수집 + 영어 파닉스/리더스 + 태블릿↔폰 실시간 연동** 웹앱입니다.
헬로카봇 캐릭터 **153종**(시즌1~17 + 쿵)의 실제 이미지가 들어 있고, 이름을 3번(따라쓰기 1 + 혼자쓰기 2) 쓰면 카봇칩을 받아 '카봇 시계'에서 소환하고 도감에 등록됩니다.
같은 화면 안의 **📕 영어 탭**에서는 파닉스 단어를 4선 노트에 쓰며 ⚡ 에너지 코어를 모으고, 코어 4개마다 카봇 **6줄 영어 리더스**가 열립니다.
영어에는 **🎧 소리 듣고 고르기(음가 구별 퀴즈 · 🖼️ 그림 힌트 ON/OFF) · ⭐ 사이트 워드 · 🧩 리더스 문장 블록 맞추기 · 🔁 영어 누적 복습(1·3·7·14·30일)** 코너가 함께 있어요.
영어 학습량은 **파닉스 낱말 1,041개 · 사이트 워드 310개 · 듣고 고르기 623문제 · 리더스 52편 · 문장 블록 312문장**으로, 단계→유닛 탭으로 묶어 탐색합니다.

- 캐릭터 이름·시즌: 헬로카봇 공식 홈페이지 아카이브(`hellocarbot.choirock.com/archive/…`)의 시즌별 회차/제품 라인 표
- 이미지: 시즌7~17은 공식 홈페이지 캐릭터 소개, **시즌1~6은 공식 아카이브에 원판 이미지가 없어** 초이락샵·쇼핑몰의 공식 제품 실사 이미지를 직접 내려받아 사용(외부 핫링크 없음)

## 1. 실행 방법

정적 파일만으로 동작합니다(빌드 없음). 폴더에서 로컬 서버를 켜고 브라우저로 열면 됩니다.

```bash
cd work/carbot-hangul
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000/index.html
```

태블릿/폰에서는 같은 폴더를 웹에 올린 뒤(GitHub Pages 등) 그 주소로 접속합니다.
`index.html?code=우리집코드` 처럼 주소에 가족 코드를 붙일 수 있어요.

`index.html` `<head>` 에는 공개 배포 대비 `<meta name="robots" content="noindex, nofollow">` 가 들어 있습니다.

### 쓰기 연습 동작
- 태블릿 펜·손가락(Pointer Events) 지원, 필압 대신 굵기 고정 + 부드러운 라운드 선
- 도구: **되돌리기 / 지우기 / 가이드(점선 보기) / 획 힌트**
- 획 힌트: 글자를 **첫소리 → 가운데 소리 → 받침** 순서로 ① ② ③ 번호와 함께 표시
- 완료 판정: 점선 글자 영역의 **덮인 비율**을 계산해 통과하면 '다음'이 열립니다(따라쓰기 34%, 혼자쓰기 18%+). 아이가 막히면 '이번엔 넘어갈래'로 한 단계 건너뛸 수 있어요.

### 난이도 자동 분류 (153종 → 51 / 51 / 51)
글자 수 · 받침 · 겹받침 점수로 정렬해 3등분했습니다. 시즌1~6 캐릭터까지 포함해 다시 나눴습니다.

- 🌱 **1단계** 짧고 받침이 없는 이름 (예: 호프, 에이스, 루크 X, 스카이, 모반)
- 🌟 **2단계** 받침이 있거나 조금 긴 이름 (예: 스톰, 가디언트, 라이캅스, 댄디, 메디언트)
- 🔥 **3단계** 겹받침·긴 이름·합체 카봇 (예: 에이스 레스큐 X, 그랜드카봇 GX, 펜타스톰, 킹다이저)

## 4. 📕 카봇 영어 출동 미션 (파닉스 + 리더스)

한글 화면 안의 탭으로 함께 있어요(별도 사이트 아님).

### 파닉스 단계 — 단모음과 장모음을 처음부터 나란히 (**낱말 1,041개 · 음가 유닛 118개**)
| 단계 | 내용 | 단어 수 | 유닛 |
|---|---|---|---|
| **Step 1 · 단모음 · 장모음 (Short & Long Vowels)** | 단어 가족(-at·-an·-ap·-ag·-ad·-am·-ed·-en·-et·-ig·-in·-it·-ip·-og·-op·-ot·-ug·-un·-ut·-all·-ell·-ill·-ump·-oss·-ock·-uck·-ash·-est·-end·-amp·-and·-ink·-ank·-unk·-old·-ind) + 매직 e(a_e·i_e·o_e·u_e) + 장모음 ee·ea + y + oo + 최소대립쌍 | **399개** | 45 |
| **Step 2 · 자음군 · 이중자음 (Blends & Digraphs)** | sh·ch·th·wh·ck·ng + bl·cl·fl·gl·pl·sl + br·cr·dr·fr·gr·pr·tr + sc·sk·sm·sn·sp·st·sw·tw·squ·shr | 229개 | 29 |
| **Step 3 · 이중모음 · 응용 (Vowel Teams & R-controlled)** | ai·ay / oa·ow / ou·ow / oi·oy / au·aw / ew·ue / igh / ie / ar / or / er·ir·ur / air·ear·eer / ore·are / oor·our | 176개 | 14 |
| **Step 4 · 심화 · 긴 단어 (Endings & Long words)** | str·spr·scr·spl·thr·ph · 묵음(kn·wr·mb) · -ing·-ed · -tion·-ture · -ly·-ful·-less · 합성어 · un-/re- · 긴 단어 · -er/-est · -ness/-ment · -ous · -al · -ic · -le · -y · -er(사람) · 학교·달·요일·기분 | 237개 | 30 |

- 한 화면에 1,000개가 쏟아지지 않도록 **단계 탭 → 유닛 탭 → 낱말 카드** 순서로 묶어 봅니다(유닛 칩에 `완료/전체` 표시).
- Step 1은 `cap ↔ cape`, `pin ↔ pine`, `hop ↔ hope`, `cub ↔ cube`, `man ↔ mane`, `quit ↔ quite` 등 **최소대립쌍 32쌍**을 카드에 함께 표시해 소리를 대비하며 익힙니다.

### 학습·보상 흐름
- 단어 카드: 그림 힌트(이모지) + 한국어 뜻 + 소리 묶음 이름, 누르면 발음(en-US)과 뜻을 읽어 줍니다.
- **영어 4선 노트**(top · 가운데 점선 · baseline · descender) 위에서 **따라쓰기 1회 → 혼자 쓰기 2회**(한글과 같은 필기·지우개·되돌리기·가이드 토글·픽셀 커버리지 판정).
- 단어를 끝낼 때마다 **⚡ 에너지 코어 +1**. 단계별로 코어 **4개마다 리더스 미션 1개**가 열립니다(Step1 14 · Step2 13 · Step3 13 · Step4 12 = **52편**).
- **카봇 리더스(4~6줄)**: 단계에 맞춘 자연스러운 문장 **6줄**(초반 미션도 6줄) + 미션 카봇 이미지, 문장별 `en-US` 읽어주기·하이라이트, **문장 탭해서 다시 듣기**, **단어 뜻 보기**, '다 읽었어요 ⭐' 기록. Step 4는 3글자 자음군·이중자음·묵음까지 쓴 긴 문장으로 이어집니다.

### 🎧① 소리 듣고 고르기 — 음가 구별 퀴즈
- 원어민 발음(`en-US` TTS)을 **듣고** 알맞은 그림·단어 카드를 고르는 청취 퀴즈입니다.
- 라운드: **짝 소리**(최소대립쌍 32쌍 · 2지선다 · 64문제) · **Step 1~4**(유닛별 4지선다 + 단계 섞기 · 249문제) · **사이트 워드 찾기**(4지선다 · 310문제) — 모두 **623문제**. 단계 탭 → 유닛 탭으로 골라 풉니다.
- **🖼️ 그림 힌트 ON/OFF**: 화면 오른쪽 위 토글을 누르면 보기 카드의 이모지(그림)가 **DOM에서 실제로 숨겨져** 원어민 소리 + 글자만으로 맞힙니다. 상태는 `state.en.ui.pic` 에 저장되어 다음에도 유지됩니다(학습 기록이 아니므로 '빈 상태' 판정에는 영향 없음).
- 정답이면 카드가 초록색이 되고 발음을 다시 들려준 뒤 잠시 후 다음 문제로 넘어갑니다. 틀리면 정답 카드를 같이 보여 주고 다시 들려줍니다.
- 문제별 기록(`state.en.quiz.q[문제id] = {t, ok, tries}`)이 남아 영어 홈에 "맞힌 문제 12 / 623"처럼 표시됩니다.

### ⭐② 사이트 워드 (Sight Words)
- 6줄 리더스에 자주 나오는 낱말 **310개** = Dolch 220 + 명사 낱말. **레벨(묶음) 탭 6개**로 나누어 봅니다: Lv.1 첫 낱말(Pre-K 40) · Lv.2 유치원(52) · Lv.3 1학년(41) · Lv.4 2학년(46) · Lv.5 3학년(41) · Lv.6 명사 낱말(90).
- 카드를 누르면 발음과 뜻·예문이 보이고, `✍️` 를 누르면 4선 노트에서 **따라쓰기 한 번**(한글·영어와 같은 필기·지우개·점수 판정). 다 쓰면 ⭐이 붙고 복습 일정이 잡힙니다.
- `🔍 찾기 놀이`는 들리는 낱말을 4장 중에서 고르는 놀이입니다(듣고 고르기 화면을 그대로 사용).

### 🧩③ 리더스 문장 블록 맞추기
- 리더스마다 **6문장 전체**를 **1번 문장 → 2번 문장 → … 6번** 순서로 **섞인 낱말 블록**으로 연습합니다(리더스 52편 × 6문장 = **연습 문장 312개**).
- 문장 번호 탭(①②③④⑤⑥)으로 지나간 문장을 다시 풀 수 있고, [다음 문장 ›]로 이어서 갑니다.
- 낱말을 순서대로 눌러 문장을 만들고, 틀리면 놓인 낱말을 눌러 빼고 다시 맞춥니다. 맞히면 문장을 소리로 들려주고 진행도가 `1 / 6문장`처럼 오르며, 6문장을 다 맞히면 미션 목록에 `🧩 문장 완성`이 붙습니다.

### 🔁④ 영어 누적 복습 (1·3·7·14·30일)
- 한글 카봇과 **같은 간격**으로 영어 파닉스 단어와 사이트 워드를 복습합니다. 처음 익히면 1일 뒤, 복습을 맞히면 3 → 7 → 14 → 30일로 늘어납니다(틀리면 간격을 늘리지 않고 내일 다시).
- **영어 탭** 맨 위 "오늘의 영어 복습" 카드에 오늘 복습할 낱말 수와 목록이 뜨고, [복습 시작]으로 짧은 복습 연습(듣고 고르기)을 합니다.
- **복습 탭**은 `함께 보기 / 한글 카봇 / 영어 낱말`로 전환하며 한글 카봇과 영어 낱말을 한 화면에 함께 보여 줍니다.

### 저장·동기화
- 영어 진행도는 `state.en` 안에 저장됩니다.
  - `words` 파닉스 단어 `{t, done, steps, srs}` · `missions` 리더스 읽음 `{read, t}`
  - `quiz` 듣고 고르기 `{ q: { 문제id: {t, ok, tries} }, last }`
  - `sight` 사이트 워드 `{ words: { 낱말: {t, done, steps, srs} }, last }`
  - `blocks` 문장 블록 `{ 미션id: {t, tries, list:[맞춘 문장 번호], idx:다음 문장, done} }` — 구버전 `{t, done, tries}` 기록은 `list:[0]`(1번 문장 완료)으로 살려 두고, 병합할 때 두 기기의 `list`를 **합집합**으로 모읍니다
  - `ui` 화면 설정 `{ pic, t }` — 그림 힌트 ON/OFF · `srs` = `{box, due, last}`(1·3·7·14·30일 일정)
- Firebase `/families/{가족코드}` 실시간 병합에 함께 실려 **단어·사이트 워드는 마지막으로 바뀐 시각(t) 최신 우선(더 최근 복습 일정은 유지), 리더스 읽음·문장 블록은 합집합, 듣고 고르기는 문제별로 맞힌 횟수·시도·시각 중 큰 값**으로 합쳐집니다. 내보내기 코드/QR에도 함께 들어갑니다.

## 5. Firebase 실시간 연동

`js/config.js` 에 프로젝트 `carbot-hangul` 설정이 **이미 내장**되어 있어, 열면 자동으로 연결됩니다.

- 저장/구독 경로: **`/families/{가족코드}`** (루트는 읽지 않음)
- 기본 가족 코드: `carbot-m7k9p2x4`
- 코드 바꾸기: ⚙️ 설정 → 가족 코드, 또는 주소에 `?code=내코드`
- 저장 형태: `{ state: {chars, gallery, en, settings, stats}, at }`
- 병합 규칙: 카봇별 `t` 최신 우선, 그림 보관함은 id 합집합, 영어 단어·사이트 워드 `t` 최신 우선(더 최근 복습 일정 유지) + 리더스·문장 블록 합집합 + 듣고 고르기 문제별 최고 기록, 통계는 큰 값 — 태블릿과 폰이 서로 덮어쓰지 않습니다.
- **업로드 안전장치**(기록이 없는 새 기기가 클라우드 기록을 덮어쓰는 사고 방지):
  1. 첫 원격 스냅샷을 받아 병합하기 전에는 **절대 올리지 않습니다**.
  2. 이 기기에서 실제로 학습·그림·설정을 바꾼 뒤에만 올립니다(연결만으로는 올리지 않음).
  3. 기록이 하나도 없는 빈 상태는 ⚙️ **기록 모두 지우기**로 직접 비운 경우에만 올립니다.
  4. 업로드는 **트랜잭션**으로, 마지막으로 병합한 그 원격 상태일 때만 씁니다. 그 사이 다른 기기가 바꿨으면 중단하고 최신 원격을 병합한 뒤 다시 올립니다.
- 오프라인/설정 비움 상태에서도 `localStorage`로 정상 동작하고, 연결되면 자동 병합됩니다.

권장 보안 규칙(`database.rules.json`) — 루트 전체 읽기는 막고 가족 단위만 허용:

```json
{
  "rules": {
    "families": {
      "$familyId": { ".read": true, ".write": true }
    }
  }
}
```

> 가족 코드를 아는 사람만 접근할 수 있는 구조입니다. 기본값도 추측하기 어려운 임의값으로 두었으니 그대로 쓰는 것을 권합니다.

## 9. 알려진 한계 / 다음에 할 수 있는 것

- **시즌1~6 이미지 품질**: 공식 원판 일러스트가 남아 있지 않아 제품 사진 기반입니다. 배경이 완전히 지워지지 않았거나 촬영 앵글이 다른 컷이 섞여 있습니다. 공식 아트를 구하면 같은 파일 이름으로 교체하면 됩니다.
- **획순 애니메이션**은 아직 없습니다(자모 순서 힌트 + 점선 따라쓰기).
- 영어 발음은 브라우저 TTS 품질에 따라 달라집니다(iOS/Android `en-US` 음성 필요). 기기 음성이 없으면 문장 하이라이트만 동작하고, **듣고 고르기 퀴즈는 소리가 나지 않아 쓸 수 없습니다**(영어 음성을 먼저 설치해 주세요).
- 리더스는 파닉스 단계에 맞춘 **4줄 고정** 이야기 20편입니다. 아이가 읽은 문장을 녹음해 확인하는 기능은 없습니다.
- 카봇 캐릭터 이미지 저작권은 **㈜초이락컨텐츠컴퍼니**에 있습니다. 가족이 함께 쓰는 개인 학습용으로만 쓰고, 공개 저장소/공개 배포 시에는 이미지 사용 범위를 다시 확인해 주세요(공개 배포 대비 `noindex` 만 넣어 두었습니다).
